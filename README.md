# Веб-мессенджер

Учебный проект — веб-приложение мессенджера.  
Реализованы базовые страницы и компоненты: авторизация, регистрация, список чатов, профиль и страницы с ошибками.

## Реализованный функционал

### Роутинг

- Страницы доступны по URL:
  - `/` — авторизация
  - `/sign-up` — регистрация
  - `/settings` — профиль
  - `/settings/userData` — редактирование профиля
  - `/settings/password` — смена пароля
  - `/messenger` — чаты
- Поддержка переходов назад/вперёд
- Корректная загрузка страницы при обновлении URL

### Авторизация и пользователь

- Регистрация, авторизация и выход
- Проверка авторизации при старте приложения
- Получение данных пользователя с сервера
- Редактирование профиля, смена пароля и аватара

### Чаты

- Загрузка списка чатов
- Создание и удаление чатов
- Добавление и удаление пользователей из чата

### Сообщения

- Подключение к WebSocket для выбранного чата
- Загрузка истории сообщений
- Отправка и получение сообщений в реальном времени
- Валидация: нельзя отправить пустое сообщение

## 🚀 Команды для запуска и сборки

В проекте используются стандартные npm-скрипты:

### Основные команды
- `npm install` — установка зависимостей
- `npm run dev` — запуск проекта в режиме разработки (Vite dev-сервер)
- `npm run build` — сборка проекта для продакшена
- `npm run start` — сборка проекта и запуск через Express сервер
- `npm run preview` — локальный предпросмотр собранного проекта

### Проверка качества кода
- `npm run type:check` — проверка TypeScript типов (без генерации JS файлов)
- `npm run lint` — проверка TypeScript кода с ESLint (правила Airbnb)
- `npm run lint:fix` — автоматическое исправление ошибок ESLint
- `npm run lint:style` — проверка CSS стилей с Stylelint
- `npm run lint:style:fix` — автоматическое исправление ошибок Stylelint
- `npm run validate` — полная проверка проекта (типы + код + стили)

#### Тестирование
- `npm test` — запуск всех тестов проекта

### Вспомогательные скрипты
- `npm run prepare` — установка Git-хуков Husky
- `npm run lint-staged` — запуск линтеров только для изменённых файлов
- `npm run test:build` — сборка тестов TypeScript в JavaScript перед запуском Mocha

## 🛠️ Технологии и инструменты

### Frontend
- **TypeScript** — статическая типизация
- **Vite** — сборка и разработка
- **Handlebars (hbs)** — шаблонизатор

### Архитектура
- **Component-based architecture** — компонентный подход
- **MVC pattern** — Model-View-Controller архитектура
- **Custom Block class** — базовый класс для компонентов
- **Event Bus** — система событий
- Централизованный state-менеджмент (store)
- Автоматическое обновление интерфейса
- Сервисы и контроллеры для работы с HTTP API

### Стилизация
- **PostCSS** — обработка CSS
- **Stylelint** — линтинг стилей

### Валидация
- **Единая система валидации форм** — валидация по blur и submit
- **Регулярные выражения** — проверка полей ввода

### API
- **Custom HTTPTransport** — класс для работы с запросами (XHR)
- **REST API** — методы GET, POST, PUT, DELETE
- **WebSocket** — сообщения в реальном врмени

### Code Quality
- **ESLint** — линтинг кода (правила Airbnb)
- **TypeScript Compiler** — строгая проверка типов
- **Stylelint** — линтинг CSS стилей
- **Mocha** — тестовый фреймворк
- **Chai** — assertions для тестов
- **JSDOM** — эмуляция DOM для тестирования
- **Husky** — pre-commit хуки
- **lint-staged** — запуск линтеров и тестов перед коммитом

### Pre-commit хуки

В проекте настроены pre-commit хуки с помощью **Husky** и **lint-staged**.

Перед каждым коммитом автоматически выполняются:
- ESLint
- Stylelint
- тесты проекта

Это позволяет предотвращать попадание ошибок и некорректного кода в репозиторий.

## Тестирование

В проекте реализованы модульные тесты с использованием **Mocha**, **Chai** и **JSDOM**.

Покрыты тестами:
- собственный роутер (Router)
- базовый компонентный класс (Block)
- модуль работы с HTTP-запросами (HTTPTransport)

Тесты располагаются рядом с тестируемыми модулями.
